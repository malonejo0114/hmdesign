휴먼디자인 웹서비스 개발 로드맵

핵심 성공 조건: 정확한 차트 계산 + 브랜드 일관 SVG 렌더링 + 유료 PDF 리포트 + 출생시간 모름 Range 퍼널.

1) 단계별 구현 및 승인 기준

MVP

  • 입력(정확/대략/모름), 무료 요약, 후보 3~5
  • 계산 API(BodyGraph.info/Bodygraph.com) + 캐시
  • Basic PDF(6~10p) + 비교표 1p

승인: 앵커4 Gate.Line 100% 일치, Asia/Seoul→UTC 로그, PDF 성공률 99%+

Production

  • Mid/Deep 티어 확장 + 후보 8개 옵션
  • A/B 테스트(넛지/카피/후보수)
  • 재발급/이벤트로그/CS 라우팅

승인: 모름 사용자 완료율 격차 +15%p 이내, 불일치 CS ≤ 1%

Enterprise

  • 멀티테넌시, 화이트라벨, 계약형 API
  • 보안/감사 로그, 레이트리밋, SLA
  • 브랜드/템플릿/도메인 분리

승인: 테넌트 데이터 분리, SLA 정책 준수

2) 빠른 스택 비교

접근계산장점리스크
API 우선BodyGraph.info / Bodygraph.com구현 속도 최고정책/가격 의존
하이브리드API + 일부 자체 로직안정 + 브랜딩표준화/QA 필요
자체 계산Swiss Ephemeris 기반통제/원가 최적화라이선스 전략 필수

3) 데이터 파이프라인(고정)

입력(birth datetime/location) → IANA TZ(Asia/Seoul) → UTC 변환 로그
→ 계산소스(API/자체) → Personality/Design activations
→ Gate/Line 매핑 → definedChannels/definedCenters 산출
→ Output JSON(definedCenters, definedChannels, activeGates, meta, range)
→ SVG 렌더 + PDF 리포트

4) Range 퍼널 카피

  • 입력: “출생시간을 몰라도 시작 가능합니다. 권위/프로필은 후보로 안내돼요.”
  • 무료: “7일은 전략+권위만 실험해도 삶의 저항이 줄어듭니다.”
  • Range: “시간을 좁힐수록 권위가 확정됩니다. 공통분모부터 안내할게요.”
  • 체크아웃: “후보별 권위·프로필·정의를 한 장 표로 정리해드립니다.”

5) QA/CI 체크리스트

체크실패 신호자동화/대응
앵커4 테스트Sun/Earth Gate.Line 불일치20~50 케이스 CI 고정
시간대/DST환경별 결과 흔들림로컬→UTC 로그 및 IANA 업데이트
Tropical 고정결과 통째로 달라짐설정 잠금 + 결과에 고정 표기
Design 88°단순 88일 고정 오해solcross 기준 구현/검증

6) 스프린트(2주)

  1. S1: 입력폼 + API 연동 + 무료요약
  2. S2: Range(3~5) + 비교표 + 결제
  3. S3: Basic PDF + 재발급 + 이벤트 로그
  4. S4: QA/CI(앵커4+경계값+시각diff)
  5. S5: Mid/Deep + A/B 테스트
  6. S6: 운영 고도화(모니터링/CS/환불정책)
